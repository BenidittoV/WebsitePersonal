# Beniditto Portfolio — Vite/React

This project is the React/Vite deployment version of the portfolio.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Vercel

Import the repository into Vercel. Framework Preset should be detected as **Vite**.
The repository root must contain `package.json`, `index.html`, `src/`, and `public/`.
